#Descripcion de los cambios realizados en este proyecto
Para esta practica utilice una plantilla de Bootstrap y la adapte para crear un panel administrativo de citas medicas llamado MediCitas.
Cambie los títulos y las opciones del menú para que estuvieran relacionados con pacientes, doctores, citas e historial clínico. También cambie las extensiones de los archivos de HTML A PHP y actualice los enlaces internos.
Primero probe el proyecto localmente utilizando laragon y después lo subi a CodeSandBox, donde pude comprobar que la pagina carga correctamente con sus estilos, graficos y demás elementos visuales.
